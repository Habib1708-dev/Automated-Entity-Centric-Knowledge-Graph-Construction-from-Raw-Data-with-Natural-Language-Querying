# Licence of this folder's data

- `data/articles/*.md` and `raw/articles/*.json` hold text from English Wikipedia. That text is licensed
  under the Creative Commons Attribution-ShareAlike 4.0 International licence
  (https://creativecommons.org/licenses/by-sa/4.0/); these files are released under the same licence. The
  authors and the source revision of each article are listed in `ATTRIBUTION.md`; the changes made are
  described there too.
- `data/lighthouses.csv`, `data/events.ndjson`, `data/engineers.json`, `raw/wikidata.json` and
  `raw/documents.json` come from Wikidata, whose data is released under CC0 1.0
  (https://creativecommons.org/publicdomain/zero/1.0/), and from Wikipedia page metadata (titles, lengths,
  revision ids).
- The share-alike licence covers the article text only, not the code of this repository: `build.py` and
  the tests are part of the kgbuilder project and are not covered by CC BY-SA.
