# C6 purity: rules for the judge

You judge whether a chunk of text concerns a start node: the thing a reader started from. A graph led
from the start to this chunk, and the graph is only useful when it leads to chunks about the start.

You see:
- the start: for a record, its label, key, name, row and relations; for any other node, its name, its
  type, and a few sentences from other places that mention it, so you know which thing it is;
- the chunk with its document.

Decide from that text and data alone. Every example below is invented and comes from no dataset you will
judge.

## The question: "Does this chunk concern this start node?"

A chunk concerns the start when it speaks of that very thing:
- for a record or an individual, that one thing, not another of the same name or kind;
- for a concept, that kind of thing.

A chunk about a piece of the start, or one that names the start in passing while saying something about
it, concerns it.

| Label | When |
|---|---|
| VALID | the chunk speaks of the start |
| VALID_ALTERNATIVE | the chunk does not name the start, but a reader would take it as about the start from its document (a later paragraph of a text about the start that goes on describing it) |
| INCORRECT | the chunk does not concern the start: it speaks of another thing of the same name or kind, or of something else entirely |
| AMBIGUOUS | the text honestly supports both |
| UNJUDGEABLE | the item does not show what a decision needs |

Examples:
- **VALID:** the start is `Oven:O-1 "Hearth Oven"`, and the chunk is a customer letter saying "the
  Hearth Oven heats evenly".
- **INCORRECT:** the start is `Fitting:H-9 "Door Hinge"`, whose relations say
  `FITTED_TO -> Oven:O-4 (Stone Oven)`, and the chunk is from a letter about the Hearth Oven complaining
  about its door hinge. That is another oven's hinge.
- **VALID:** the start is the concept "rising time", and the chunk says the dough "took four hours to
  rise".
- **INCORRECT:** the start is the individual "Mara Quist" (the head baker, from the sentences shown), and
  the chunk is about a different Mara Quist, a supplier in another town.

## Every verdict

- `id`: the item's id, exactly.
- `label`: one of the five labels.
- `reason`: one line saying why.
- `evidence`: a quote copied verbatim from the chunk or the start's record or sentences that decides it.
  Only UNJUDGEABLE may leave it empty.
- Judge each item on its own. Do not guess what the graph or any code thinks about it.
